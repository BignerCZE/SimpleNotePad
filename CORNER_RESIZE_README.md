# SimpleNotePad 2.4.0 – obrázky s tažením za rohy

## Výchozí vložení
- obrázek menší nebo stejně široký jako editor se vloží v původní pixelové velikosti,
- širší obrázek se automaticky zmenší na dostupnou šířku editoru,
- poměr stran je vždy zachován.

## Změna velikosti tažením
- klikni na obrázek,
- v rozích se zobrazí čtyři malé modré úchyty,
- táhni kterýmkoli rohem,
- velikost se mění plynule se zachováním poměru stran,
- kliknutí mimo obrázek výběr zruší.

## Horní menu
Soubor | Úpravy | Formát | Obrázek | Nápověda

Menu Obrázek:
- Vložit ze schránky
- Zmenšit o 10 %
- Zvětšit o 10 %
- Nastavit přesnou šířku...
- Původní velikost
- Přizpůsobit šířce okna

Ovládací prvky změny velikosti byly odstraněny z toolbaru.

## DOCX
Aktuální velikost obrázku se ukládá přímo do DOCX a po opětovném otevření se obnoví.
