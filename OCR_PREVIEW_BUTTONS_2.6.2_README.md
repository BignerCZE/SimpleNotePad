# SimpleNotePad 2.6.2 – tlačítka v OCR náhledu

Dialog „Náhled rozpoznaného textu“ má nově jasně viditelný spodní panel:

- Vložit text
- Zrušit

Panel je přímo pod editovatelným textovým polem a zůstává viditelný.

Klávesové zkratky zůstávají:
- Esc = Zrušit
- Ctrl+Enter = Vložit text

V levé části spodního panelu je navíc krátká připomínka klávesových zkratek.
