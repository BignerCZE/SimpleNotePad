# SimpleNotePad 2.6.1 – OCR náhled a ruční oprava textu

Po úspěšném OCR se text už nevloží okamžitě do poznámky.

Nový postup:
1. Uživatel vloží screenshot/obrázek.
2. Zvolí „Převést na text“.
3. Windows OCR text rozpozná.
4. Otevře se dialog „Náhled rozpoznaného textu“.
5. Rozpoznaný text je zobrazen ve velkém editovatelném poli.
6. Uživatel může opravit chyby, diakritiku, mezery nebo zalomení.
7. „Vložit text“ vloží upravenou verzi do poznámky.
8. „Zrušit“ nevloží nic.

Další vlastnosti:
- pole je vícerádkové,
- obsahuje scrollbar,
- podporuje Undo v rámci náhledu,
- Escape dialog zruší,
- Ctrl+Enter potvrdí vložení,
- zobrazuje použitý OCR jazyk, pokud je dostupný.

OCR zůstává lokální a obrázek se nikam neodesílá.
